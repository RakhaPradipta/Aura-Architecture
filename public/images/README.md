## Image Specs

| Use Case | Min Size | Aspect Ratio | Format |
|---|---|---|---|
| Project hero | 1920 × 1080 | 16:9 | `.jpg` or `.webp` |
| Project detail | 1200 × 800 | 3:2 | `.jpg` or `.webp` |
| Gallery | 1200 × 900 | 4:3 | `.jpg` or `.webp` |
| Team headshot | 600 × 800 | 3:4 | `.jpg` or `.webp` |
| Page hero bg | 1920 × 1080 | 16:9 | `.jpg` or `.webp` |
| About images | 1200 × 800 | 3:2 | `.jpg` or `.webp` |

## Tips

- Use `.webp` for smaller file sizes with no visible quality loss
- Compress to ~200-400 KB per image for fast loading
- Keep consistent color grading across a project's set
- Hero images should be wide-angle; detail images should be closer crops
